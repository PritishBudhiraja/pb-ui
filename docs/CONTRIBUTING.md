# Contributing

Follow `AGENTS.md`. Run `pnpm lint`, `pnpm test`, `pnpm build`, and `pnpm test:pack` before opening a PR. Add a changeset for publishable package changes. Releases: GitHub Actions `Release` workflow (`@pritish.budhiraja/tokens` and `@pritish.budhiraja/ui` on npm). Do not stop at expanding Hatch unless a real app needs a new primitive.
